# Code of Conduct

## Our pledge

Signetry is a security project. We want contributing here to be productive,
respectful, and free of harassment for everyone, regardless of experience level,
background, or identity.

## Expected behavior

- Be respectful and constructive. Critique ideas and code, not people.
- Assume good faith; ask questions before assuming intent.
- Keep security discussions responsible — report vulnerabilities privately
  (see each repo's `SECURITY.md`), never in a public issue.
- Respect the project's licensing: Signetry is
  [open core](https://github.com/Signetry/signetry/blob/main/LICENSING.md) — the integrations
  are Apache-2.0, the kernel is BUSL-1.1 until 2030-08-31. Contributions are made under the
  [CLA](https://github.com/Signetry/signetry/blob/main/CLA.md).

## Unacceptable behavior

Harassment, personal attacks, discriminatory or demeaning comments, publishing
others' private information, and deliberately disruptive behavior are not tolerated.

## Enforcement

Maintainers may remove, edit, or reject contributions, comments, and issues that
violate this code, and may block repeat or serious offenders. Report concerns to
the owner via a private channel (GitHub private vulnerability reporting or a direct
message to the maintainer).

## Scope

This applies in all project spaces — repositories, issues, pull requests,
discussions — and when representing the project in public spaces.

Adapted in spirit from the Contributor Covenant.
